## 环境与范围

使用已运行的Electron开发版（localhost:8849），主资料库为win（ID 3），跨库隔离只查看测试删除仓库（ID 4）。没有进入第一个资料库，没有build或重启主进程。测试通过真实UI发起，使用当前配置的gpt-5.5，工具事实通过只读SQLite查询交叉核对。

## 发现与修复

首次点击“新建会话组”时，按钮有响应但弹框不显示。新组编辑器与新建/移动会话选择器均为条件挂载且初始visible=true，触发Semi Portal在React StrictMode挂载重放中的已知问题。

两个组件改为先隐藏挂载，再在effect中打开，不关闭StrictMode，不修改通用Modal。热更新后新组创建成功；重新打开组设置、新建会话、移动会话的弹框均实际显示，页面重新加载后也可用。
