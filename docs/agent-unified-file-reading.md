# Agent 统一文件读取

更新时间：2026-09-08

## 当前能力

文件工具使用 `scope=library|host`。默认 library，表示当前资料库；host 必须明确本机绝对路径或 `~/` 路径。路径命名空间不根据文件是否存在自动猜测，不把资料库路径当作本机路径。

- `file.list`：列出一层目录，默认 50 条、最多 100 条。
- `file.search`：在路径子树按名称字面包含、glob 和类型筛选；不区分大小写，不搜索正文，不解释正则或管道。
- `file.stat`：元数据；资料库可附带存储健康观察，不代表正文已读。
- `file.resolve`：精确路径定位；调用 read/list 时不是必要前置步骤。
- `file.read`：UTF-8 正文，返回带行号的结构化文本片段。
- `file.grep`：按单行字面文本搜索正文，返回路径、行号、上下文和有界续搜游标。完整契约见 [文件与正文搜索](agent-file-search.md)。

资料库 ID、directoryId 和标签只属于 library，不透传给 host。资料库仍通过 renderer authority 和 HTTP 读取数据库；本机在 Electron main 读取，两者不经过 Shell 命令拼接。

## 正文契约

输入：`scope`、`path`、`offset`、`column`、`limit`、`revision`。

offset 为一基行号，默认 1；column 为一基 Unicode 字符位置，默认 1，不是 UTF-16 下标或字节位置。limit 默认 200 行、最多 2,000 行，实际返回量同时受约 6,000 字节正文页预算约束。

输出包含 `scope/path/revision/offset/column/lines/totalLines/hasMore`。lines 的每项为 `{line,column,text}`；存在剩余内容时附带 `nextOffset/nextColumn`。下一次读取相同路径并传这两个位置及 revision。内容 hash 变化时拒绝续读，不能把新版文件接在旧版片段后。CRLF/LF/CR 统一为逻辑行，文件末尾换行不产生多余空行。

长行只交付可容纳的字符，下一页从该行剩余 column 开始，不跳过中段。最终模型上下文不足以完整交付正文页时终止本轮并说明未交付，不能使用截断后的 nextOffset；这不同于 Shell 日志保留头尾的显示策略。

## 边界与授权

- 单文件上限 8 MiB，UTF-8 严格解码；二进制控制内容及 PDF 不作为正文返回。不支持自动 Office/PDF 解析、OCR 或字符集猜测。
- 本机复用安全打开普通文件的 helper：拒绝最终路径符号链接、特殊文件及多硬链接，打开和读取后检查文件身份。路径的中间目录可能存在正常的系统链接，此实现不是 OS sandbox。
- host 操作在 Run 冻结的 full-access 下允许，ask/auto 进入现有一次性审批；library 读取仍受当前用户、资料库、窗口、Session、Run 和 ToolRun 绑定。
- 资料库正文复用 stage-library-node authority 获取短期 URL，不产生 workspace staging 文件；下载限制 8 MiB，取消和超时会结束读取，读取后重新检查授权及节点身份，工具额外检查路径未漂移。
- 资料库正文具有 main-only 的 Run 内有界缓存：按 owner、窗口、资料库、Session、Run 和节点隔离，最多 16 项 / 16 MiB，60 秒过期，Run 结束主动释放。仅强 ETag 可以缓存；续读重新取得授权，以 `If-None-Match` 条件 GET 访问源存储。304 复用正文，200 重新读取；禁用 Chromium 隐式 HTTP 缓存。没有 ETag 时退回完整读取，离线、拒绝访问或身份漂移时废弃缓存并报错，不把旧内容伪装成在线读取。
- URL、存储对象键和凭据不返回模型；正文仍通过既有 Tool 结果脱敏管线。正文是不可信内容，不授予工具权限。

本机目录搜索最多扫描 5,000 项，不递归符号链接；更大范围明确建议缩小目录或使用 Shell。游标绑定查询条件和扫描结果指纹，目录变化后拒绝旧游标，不伪装成完整结果。目录树查询不是原子文件系统快照。

## 输出预算

内部目录元数据最多 100 条、24,000 UTF-8 字节。renderer 收到超大页面后保持原游标和筛选条件，内部减半 limit 重查，返回实际交付页对应的 nextCursor；不直接截断条目数组后复用原页游标。最多从 100 缩到 1，不无限重试。

正文与文件元数据的单次模型投影上限为 10,000 tokens，仍受当前上下文剩余量限制。本机目录按约 20,000 字节条目预算打包续页。

## 尚未实现

这不是资料库 FUSE 挂载或 Shell 管道解释器。本机复杂 `rg/sed`、正则和管道继续使用现有 Shell；内部正文搜索是有界逐文件读取，没有全文索引。首次读取、缓存失效或没有强 ETag 时完整读取最多 8 MiB，再切片；缓存有效且源返回 304 时无需再次传输正文。尚未实现 Range 续读或行索引，续读仍有权限、元数据与条件请求开销。后续优化必须保留版本检查、取消、字节与对象数量上限。
