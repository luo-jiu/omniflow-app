# M1 插件命令与手动执行

更新时间：2026-09-23

状态：已完成本批 macOS 手动执行核心验收。文件菜单、参数表单、拒绝及真实新文件保存已验证；不扩大 W0～W4 的既有验收范围。

## 1. 目标与交付范围

用户从文件右键菜单或工具工作区直接调用已安装插件，完成批量改名、CSV 导出及 JSON 转换，不必通过模型对话。服务于资料整理、处理与再利用；遵守[项目长期方针](../../PROJECT_PRINCIPLES.md)的原件保护、任务提交核对和唯一状态 owner 原则。

复用已安装包、隔离 Tool runtime、资源 broker、改名提案和文件产物服务。不给插件新增任意宿主命令、React 组件、网络或直接写文件能力；不增加后端插件专属 API。

## 2. 实施步骤与验收

1. SDK 声明命令别名及固定菜单位置，校验同包引用、命名空间和能力批准；现有三个样板升级。
2. main 建立独立手动执行记录，复用准备、完整预览、批准、提交和回执核对；不创建 Agent 对话或模型 Run。
3. 工具页按有限参数 schema 生成表单，承接文件选择和目标目录；目录右键携带捕获的选择进入同一页面。
4. 覆盖授权独立性、过期批准、取消/未知提交、恢复记录、表单与入口；执行 lint、全量测试和构建，做一条 macOS 代表性交互及边界验证。

## 3. 命令声明与权限

SDK 0.6.0，wire 仍为 1、Manifest 为 2。新增可选 `commands`，每项为 `id / title / toolId / locations`；位置只允许 `file-menu`、`tool-workspace`。命令是同包 `agentTools` 的声明式入口，使用原 `tool:<toolId>` activation 和 HTML entry。旧包不声明命令时行为保持。

手动入口与模型 Tool 暴露分开：手动执行不依赖 `agent.tools` 或 `toolApproved`，但仍要求包启用、未被恢复模式阻断及该能力独立批准。模型目录继续要求 `agent.tools + toolApproved`。仅手动使用的包可以省略 `agent.tools`，其 Tool 必须有命令别名；读取、重命名、产物权限不因此放宽。

菜单只传可序列化的 ID/标题。overlay 返回命令后，主 renderer 对照菜单打开时的贡献和当前 catalog 再检查，并只使用捕获的节点 ID；main 在执行时重新验证来源、包指纹、账号、窗口、库及能力。菜单 ID 和 renderer 过滤不作为安全边界。

## 4. 用户路径与状态 owner

工具导航增加宿主 `omniflow.plugin-commands`，原五个工具及布局 ID 保持。文件菜单支持单文件命令和最多 50 个普通文件的改名提案；混合目录选择不显示这些入口。选择变化不会改写已经准备的动作。

页面 owner 只持有工作区模式和一次打开请求。表单草稿属于工具组件；执行、批准、结果和回执记录由 main 持有，renderer 消费带 revision 的投影。切换工具面板不取消任务；离开资料库或退出账号释放本次执行，已提交或未知事实保留。返回页面读取现有记录，不自动重跑。

写命令必须先展示完整改名前后列表或新文件目标、大小、格式和摘要，再按执行 ID 与 revision 批准。main 批准前重准备，内容变化产生新预览；旧批准不能继续写入。只读命令可以直接返回结果。

## 5. 提交与恢复边界

手动任务独立于 Agent SQLite 对话保存，由 `PluginCommandStore` 持有 `plugin-command-history-v1.json`。最多 500 条、12 MiB；容量满时只淘汰最旧明确终态，未知记录不自动淘汰。批准、提交与未知 operation 身份在 main 持久化并在派发前 fsync；上传仍用同一事务和严格目标目录，文件产物仍为同库新文件、同名报错。取消不等于撤销，提交结果不明时保留原 operation，仅允许显式查询回执，不自动重试。

共享服务内部沿用的 scope 关联字段不代表创建了模型会话。历史回执查询不依赖插件仍启用，也不重新运行插件；当前账号/资料库访问和后端回执元数据仍需核对。重启将 preparing/awaiting-approval/executing 转为 interrupted，不能继续原批准；提交前已经持久化的 commit-unknown 保留。最多 8 个活动任务，10 分钟到期取消；窗口销毁、离库、注销及能力撤销同样取消。记录损坏只禁用手动命令，不清空原文件或阻断其他插件功能。

处理参数、产物正文、私有 binding 与凭据不进入该历史文件；只读 Tool 的有界结果按执行结果保存。文件产物未知结算以 `uploadCommitState` 判定，改名以 `mutationCommitState` 判定。显式查询保留原结果及最近 8 次核对，不重新运行插件。
