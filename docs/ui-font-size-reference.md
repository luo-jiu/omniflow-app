# UI Font Size Reference

更新时间：2026-05-04
适用范围：`omniflow-app` 前端界面中的通用字体尺寸参考。当前先记录视频播放页已实际落地的处理，后续再逐步扩展到更多页面。

## 1. 作用

这份文档不是一次性“设计稿说明”，而是前端后续统一字号时的起点。

当前项目里很多页面的文字尺寸不完全一致，所以先从已经实际调整过的页面开始记：

- 先写“当前事实”
- 不先假装全项目已经统一
- 后续别的页面要跟进时，再继续把真实处理补进来

## 2. 当前已落地页面

目前只记录：

- `VideoViewer`
  - `src/features/file-viewer/components/video-viewer/style.ts`

## 3. 当前参考层级

`VideoViewer` 里当前抽成了 4 个局部字号层级。2026-05-04 起，视频页也进入 `100%` 页面缩放迁移后的紧凑工作区密度：

- `--video-font-caption: 10px`
  - 轻提示、小标签、说明型字段名
- `--video-font-body: 11px`
  - 次级正文、说明、时间、按钮小字、状态标签
- `--video-font-control: 12px`
  - 控制器里的主要操作文案、信息值
- `--video-font-title: 14px`
  - 区块标题

## 4. 本次视频页实际使用

### 4.1 底部控制器

- 时间文本
  - `11px`
- 底部控制器中的文字按钮
  - `12px`
- 音量 / 倍速弹出面板里的按钮
  - `11px`

额外处理：

- 底部控制器里的按钮内容统一改成 `line-height: 1`
- 按钮内容使用 `inline-flex + align-items: center`

这样做的目的，是把“文字整体有点偏下”的观感往上收，让控制条里的字和图标更居中。

### 4.2 右侧工具台

- 区块标题
  - `14px`
- 区块说明
  - `11px`
- 元信息
  - `11px`
- 字段 label
  - `10px`
- 主要值
  - `12px`
- 预留能力标签
  - `11px`

### 4.3 字幕预览区

- 预览区文本
  - `12px`

注意：

- 这里说的是右侧工具台里的“字幕预览区”
- 不是视频主画面上的实际字幕覆盖层
- 主画面字幕大小仍由用户可调，不属于固定通用字号

## 5. 当前结论

基于 `100%` 页面缩放迁移后的实践，视频页当前比较稳的一组层级是：

- `10px`
  - caption
- `11px`
  - body / meta
- `12px`
  - interactive control / value
- `14px`
  - small section title

这组值是针对“恢复 Chromium `100%` 页面缩放后，视频页仍接近旧舒适缩放观感”的当前事实。主画面字幕大小仍由用户可调，不跟随这组固定工作区字号。

后续如果其他页面也开始统一，优先先看能不能落在这 4 档里，再决定是否真的需要更多字号层级。

## 6. 维护规则

出现以下情况时，必须更新本文：

- 其他页面开始按统一字号重构
- `VideoViewer` 的字号层级发生变化
- 新增了全局通用字号 token
- 某个页面明确证明这 4 档不够用，需要新增层级
