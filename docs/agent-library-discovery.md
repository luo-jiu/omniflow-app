# Agent 资料库目录发现

更新时间：2026-09-08

## 当前能力

Agent 可读取当前资料库的元数据，不要求用户先展开目录树或选中文件。内部操作是默认偏好，不是宿主机操作禁令。

- `file.list`：按目录 ID 或资料库绝对路径列出一层子节点，默认每页 50 条，最多 100 条。
- `file.search`：按名称片段、类型、标签搜索，可限定目录子树；不搜索文件正文。
- `file.resolve`：逐段精确解析 `/音乐` 等资料库路径，拒绝歧义、缺失和路径变化，不自动创建目录。
- `file.stat`：按 ID 重新读取节点，并可附带存储可达性观察；元数据存在不等于文件内容可读。

浏览和搜索只查询数据库，不依赖 MinIO 在线，也不创建或修复根节点。返回规范路径、节点身份、父目录、大小、类型和脱敏存储标识，不返回对象键、物理地址或凭据。

## 分页与状态

`hasMore=true` 时，用 `nextCursor` 和相同筛选条件继续。游标绑定筛选条件；可以减小 `limit`。分页不是数据库快照，并发移动、删除或新增可能改变后续结果。

主进程复用 file authority 的 owner / session / run 绑定通道，校验资料库范围和安全字段。单页最多 24,000 UTF-8 字节；renderer 在超限时自动减小页大小、从原游标重试。最终模型预算仍不足时明确报告未交付，不能用未交付页面的下一页游标跳过数据。

统一 `scope=library|host` 和新增 `file.read` 正文契约见 [Agent 统一文件读取](agent-unified-file-reading.md)。内部查询默认不变，本机路径必须显式选择 host。

查询到的节点作为 Run 内最多 500 条有界读取缓存，供后续媒体工具使用；保存返回的新节点按 ID 合并，不覆盖全部旧发现。缓存不是写授权，也不替代 UI 当前目录或选中项。

## 直接保存到目录

`media.extractAudio` 支持互斥的 `directoryPath` / `parentId`。准备阶段解析实际目标，并冻结目录 ID、资料库与规范路径；执行前和上传前重新验证。路径变更、目录消失或跨库时停止，不静默改存本机。

目标不同于 UI 当前目录时仍直接走资料库上传；成功验证实际输出节点，不把 UI 当前目录改成目标目录。审批中编辑目标后重新 prepare，使用编辑后的目录，不复用模型最初的路径。

本机输出仍可显式选择 `destination=local`，但不能同时指定资料库目标。原有源文件可读性、健康存储选择、权限和一次性执行绑定保持有效。

## 验证与部署

自动化覆盖路径精确匹配、扩展名、歧义、分页边界、范围拒绝、搜索后媒体检查、目标变更阻止执行、跨目录上传与 UI 目录保持。测试禁止使用第一个资料库。

需要同时更新 Go 服务（新增 `POST /api/v1/nodes/metadata/query`）和重启 Electron 主进程。只热更新 renderer 不足以启用新工具。
