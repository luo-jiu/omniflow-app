# E1 目录型只读查看器与漫画样板

更新时间：2026-09-22

## 当前范围

E1 在 D2 只读平台之上增加普通 `COMIC` 目录接管。独立漫画样板使用公开 SDK 读取直属图片、单页翻页、恢复阅读位置；既有内置漫画查看器保留。不是把原漫画 React 组件搬入插件，也不提供内置滚动、双页、缩放和平移的完整功能等价替换。

不包含归档漫画、递归目录、写入 `viewMeta`、主题扩权、图标重绘、Windows/Linux 验收。漫画插件以可安装 ZIP 样板交付，不自动安装到用户配置，不随 CSV 的内置授权运行。

## 能力与权限

- SDK npm 版本 `0.2.0`，wire/Manifest `sdkVersion` 继续为 1；旧 CSV/JSON 的清单、响应和读取配额兼容。旧宿主会拒绝含新增权限/匹配字段的包，不能降级为普通文件授权。
- 目录贡献声明 `directoryTypes: ["COMIC"]`、`extensions: []`，且同时声明 `directory.read` 和 `resource.read`。当前文件贡献仍使用非空 extensions；同一贡献不能混合两类匹配，一个包可有不同贡献。
- 安装预检显示新增权限；包版本改变仍需重新启用、批准读取。打开后另对当前目录授权，范围是直属图片，不包含任意兄弟节点、子目录或祖先目录。
- 候选匹配只开放 `comic`，不开放 `comic_archive`。安装不改变默认值；用户显式选择或保存关联后才接管。目录关联键固定为 `comic:`，目录名中的点号不被当成文件扩展名。
- main 根据已校验包的贡献选择目录 adapter，不接受插件提供 nodeId/URL，不按 `example.comic` 特判。主进程再次验证实际节点为目标库的非归档 COMIC 目录。

## 资源契约

`context().resource.kind === 'directory'` 表示目录，size 为 0，不能直接 `read`。旧文件上下文不要求 kind 字段。

1. `listDirectory(handle, offset=0, {signal})` 返回固定快照的图片条目、下一偏移、eof、revision。每页最多 64 项；条目只含不透明 ID、名称、长度、MIME。顺序沿用后端 `sortOrder, id`；不把正文、存储路径或签名链接投影给插件。
2. `openDirectoryEntry(handle, entryId, {signal})` 仅接受快照已包含的条目，按需换取本实例文件句柄。不得用节点 ID、其他目录条目或其他实例句柄替代。
3. `read(childHandle, offset, length, {signal})` 沿用 Range + strong ETag 校验，读取前后验证父目录仍获准、子节点仍在原父目录/库且内容版本未变化。
4. `releaseResource(childHandle)` 释放文件句柄。并发读取即使底层忽略取消，释放后迟到字节也不交付。撤权、关闭、切库、切账号和管理页停用沿用旧实例销毁链路，清空所有子句柄。

后端复用 `GET /v1/nodes/:id`、`GET /v1/nodes/:id/children?libraryId=...` 和原签名链接 API，没有修改后端契约或数据库。children 接口本身不分页；main 将响应限制为 2 MiB、最多 512 个直属节点，超限明确报 LIMIT，不能静默截断后宣称完整。SDK 的分页是对这个有界内存快照分页。

首次目录枚举不是数据库事务快照。新加入文件需要重新加载才能出现；读取时对子节点 parent/library 重新验证，因此移出或删除的旧条目会拒绝读取。子文件 ETag 在按需打开时固定；目录 revision 表示有序条目元数据，不代表预先下载并固定所有对象版本。阅读位置绑定目录快照与插件身份，目录列表变化会使旧快照失效；同名同大小文件替换时允许保留页位置，但文件字节仍按新句柄固定版本。

首批支持扩展名 jpg/jpeg/png/webp/gif/avif/bmp，忽略以点开头的文件，不读 SVG、子目录或其他正文。后端 metadata 与实际图像解码分别负责识别和验证。

## 配额与生命周期

| 范围 | 预算 |
| --- | --- |
| 直属节点快照 | 最多 512 节点 / 后端响应 2 MiB |
| SDK 枚举页 | 最多 64 条 |
| 子文件句柄 | 每实例最多 4 个，正在打开也占槽位 |
| 文件长度 / 分块 | 每文件 32 MiB / 每块 64 KiB |
| 目录实例累计读取 | 512 MiB，重复读仍计费 |
| 目录实例普通请求 | 16384 次；仍受 64 次/秒、8 并发、4 秒超时限制 |
| 普通单文件实例 | 原 32 MiB 累计 / 4096 请求不变 |
| 漫画样板显示 | 单张最多 10 MiB / 2400 万像素，只保留当前图片 |

总预算耗尽要求显式重新加载或切回内置查看器。样板逐块限速，避免本机存储过快超过 RPC 频率；不预加载整本漫画，不累计所有 base64。显示走既有 CSP 允许的 data 图片，不新增网络出口、blob 权限、磁盘缓存或特权图片 URL。

图片解码运行在隔离 renderer，宿主现有 256 MiB 工作集、CPU/心跳预算仍执行；解码超时或失败会清空图片并显示错误。大图可能触发宿主内存保护，这一阶段不宣称大图性能验收完成。

阅读状态复用 B2/C2 Viewer Session，不另建 tab 或媒体 owner。不读写内置漫画 `viewMeta`；插件与内置的阅读进度各自隔离。主题通过原 SDK 事件更新，停用后保留默认关联，临时回退不会覆盖用户偏好。

- `node tools/plugin-isolation/build-independent.mjs comic-viewer`：仓库外打包 SDK、离线构建，输出 packageDirectory。
- 在输出的 sample 目录执行 `npm run package`，生成 `plugin.zip`；通过设置 → 插件管理安装、启用、批准读取。
- `node tools/plugin-isolation/run.mjs --e1`：隔离临时 profile、回环合成 API 与 PNG，无真实资料库读写。验证正式安装、主窗口 IPC、主进程授权、隔离图片解码、翻页、快照恢复、节点移出拒绝和管理页撤权销毁。

- 真实资料库人工验证只能用非第一个资料库；优先 win（ID 3）与本机 macOS MinIO。需验证默认打开方式、侧栏/overlay、亮暗主题、切 tab 与长漫画资源趋势，未做前不能宣称 E1 完整用户验收完成。
